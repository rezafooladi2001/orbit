# Orbit Bot Project

پروژه جدید Orbit Bot

## راهنمای استفاده

این پروژه برای مدیریت bot orbit استفاده می‌شود.

## نصب و راه‌اندازی

```bash
# Clone پروژه
git clone <repository-url> orbit
cd orbit

# نصب dependencies
npm install
```

## Build

```bash
npm run build
```

## Deploy

برای deploy روی سرور، از راهنمای `DEPLOYMENT.md` استفاده کنید.
